# Organise Downloads

How DJ tidies the Downloads folder.

1. Ask which days (today, yesterday, last N days, everything).
2. Plan the moves and show the full list first.
3. Nothing moves until the user says Yes.
4. Move the files, write every move to the log, and report what
   moved and what failed.

Never overwrite a file. Never move a file outside Downloads
without the user naming the destination.
